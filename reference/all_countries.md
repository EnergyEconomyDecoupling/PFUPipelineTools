# Country abbreviations

A string list containing all known countries in abbreviated format.
3-letter codes are analyzed as separate countries. The 3-letter codes
conform to ISO naming conventions. 4-letter codes are not ISO codes but
still analyzed as separate countries. 5-letter codes (and longer) are
aggregations.

## Usage

``` r
all_countries
```

## Format

A string list with 166 entries.
