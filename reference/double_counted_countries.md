# Double-counted countries

A string list containing abbreviated names of double-counted countries.

## Usage

``` r
double_counted_countries
```

## Format

A string list with 9 entries.

## Examples

``` r
double_counted_countries
#> $afri
#> [1] "AFRI"
#> 
#> $asia
#> [1] "ASIA"
#> 
#> $bunk
#> [1] "BUNK"
#> 
#> $eurp
#> [1] "EURP"
#> 
#> $mide
#> [1] "MIDE"
#> 
#> $namr
#> [1] "NAMR"
#> 
#> $ocen
#> [1] "OCEN"
#> 
#> $samr
#> [1] "SAMR"
#> 
#> $wrld
#> [1] "WRLD"
#> 
```
